Logbook

Evidence from a self-hosted VLAN-segmented home lab running a production-grade honeypot, SIEM, and firewall stack. Everything here is captured from real traffic hitting a live environment.

01

Lab Infrastructure

The entire stack runs on a single physical host. Building it from scratch — rather than using a managed service — means owning every configuration decision, from hypervisor to VLAN tagging to firewall policy.

PROXMOX VE · VM INVENTORY

Five VMs running concurrently on a single physical host: the OPNsense firewall, Wazuh SIEM manager, Cowrie honeypot, and supporting services. Uptime across the board confirms persistent operation, not a one-time demo.

802.1Q VLAN CONFIG · MANAGED SWITCH

VLANs 10 (Trusted), 20 (Honeypot), 30 (Management), and 40 (IoT) defined with explicit tagged/untagged port assignments. Port 1 carries the trunk to the router; each downstream port lands on exactly one VLAN.

02

Network Security Architecture

Every rule in the firewall was written intentionally. Inbound SSH is redirected to the honeypot via NAT. The Trusted VLAN is explicitly blocked from reaching the Honeypot network. These aren't defaults — they're design decisions you can read directly from the ruleset.

OPNSENSE · FIREWALL RULES

The ruleset shows deliberate segmentation: inbound SSH from WAN is passed to the honeypot, Trusted network is explicitly blocked from reaching Honeypot network, and a separate rule gates admin access to the Cowrie VM on a non-standard port. Rule descriptions are written to be auditable.

OPNSENSE · LIVE FIREWALL LOG live traffic

Live log showing real external IPs matching Allow inbound SSH to honeypot and triggering the rdr redirect. Each inbound connection generates three log lines — WAN in, NAT redirect, and Honeypot out — confirming the full redirect chain is functioning. Destination IPs are redacted.

03

Threat Detection & SIEM

Wazuh aggregates logs from across the lab and correlates them against MITRE ATT&CK. The dashboards below were built to give a quick operational read on threat volume, attack technique distribution, and honeypot activity.

WAZUH · CUSTOM SOC DASHBOARD

43,104 total alerts in the last 24 hours; 42,184 (97.9%) from the honeypot. Top destination port is SSH at 100% — the entire exposed attack surface is deliberate and contained. The dashboard was built to give a one-glance read on honeypot activity versus everything else.

WAZUH · AGENT OVERVIEW · DOLOS

MITRE tactic distribution over 24 hours: Execution at 8,292 events, with Defense Evasion, Initial Access, Persistence, and Privilege Escalation each at 4,673 — a pattern consistent with credential stuffing followed by automated post-login enumeration.

WAZUH · MITRE ATT&CK DASHBOARD

Filtered to agent 004 (DolosHoney). The alert cadence chart shows repeated burst cycles; the bar chart breaks down attack volume by MITRE tactic. Seeing the pattern — not just individual alerts — is what distinguishes detection from monitoring.
